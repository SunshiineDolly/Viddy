Viddy 0.26.7 repairs playback and update identity on Mac.

- Mac playback controls and progress now use an in-app player bridge with the YouTube API running at a stable HTTPS origin.
- Mac previews use the same HTTPS player host.
- Playback errors no longer automatically open a separate window.
- Mac releases use a stable signing identity to preserve Keychain trust across future updates.
- Mac explicitly restarts after successful update installation.
- Muted video previews keep their separate Playback setting.
