Viddy 0.26.8 improves automatic playback on Mac.

- Selected videos explicitly start through the player API when ready.
- Muted hover previews retry a blocked start before falling back to the thumbnail.
- Nested player frames explicitly receive autoplay permission.
- Paused watch-together sessions and deliberate pauses stay paused.
- Mac updates retain the stable signing identity introduced in 0.26.7.
